# Front-End Week 1: 아코디언 인터페이스

순수 **HTML/CSS/JS**만으로 만든 **아코디언(Accordion) UI**입니다.  
두 가지 버전—**단일 오픈(한 번에 하나만 열림)**과 **다중 오픈(여러 개 동시 열림)**—을 한 페이지에서 비교하며 구현했습니다.  
`max-height + scrollHeight`로 부드러운 열림/닫힘 애니메이션을 만들고, `active` 클래스로 상태를 제어합니다.

## ✅ 기능

- 클릭으로 **콘텐츠 열림/닫힘 토글**
- **단일 오픈**: 현재 열려 있는 항목을 닫고 새 항목만 오픈
- **다중 오픈**: 여러 항목을 동시에 오픈 가능
- **부드러운 전환 애니메이션** (`transition` / `max-height`)
- 활성 상태에서 **타이틀 화살표 회전** (CSS로 처리)

## 💡 구현 포인트

- 각 `.accordion-item`에 `active` 클래스를 부여/제거하여 상태 관리
- 콘텐츠 영역은 `max-height: 0`에서 시작 → 열 때 `scrollHeight`로 자연스러운 높이 전개
- 단일 오픈: 모든 항목을 초기화한 뒤, 클릭한 항목만 `active`
- 다중 오픈: 클릭한 항목만 `active` 토글
