# Front-End Week 1: 탭 인터페이스

순수 HTML/CSS/JS만으로 만든 **탭 전환 인터페이스**입니다.  
`data-tab` 속성과 `classList`를 활용해 버튼 클릭 시 대응되는 콘텐츠를 전환하도록 구현했습니다.

## ✅ 기능

- 버튼 클릭으로 **탭별 콘텐츠 전환**
- 활성화된 탭 버튼에만 **스타일 강조**
- CSS로 전환 시 **부드러운 시각적 변화 효과**
- JavaScript로 **`active` 클래스 동적 제어**

## 💡 구현 포인트

- 각 버튼에 `data-tab` 속성 부여 → 클릭 시 해당 콘텐츠 ID 매칭
- `classList.add/remove('active')`로 활성 상태 전환
- 모든 탭/콘텐츠를 초기화 후 선택된 요소만 활성화
- `flex-grow`를 사용해 **버튼 너비 균등 배치**

## 🔁 React + TypeScript 변환 계획

1. 탭 상태를 `useState`로 관리 (`activeTab`)
2. 버튼 클릭 시 상태 변경 → 조건부 렌더링으로 콘텐츠 표시
3. 탭 리스트를 배열로 관리해 `map()`으로 자동 렌더링
4. CSS 모듈(`Tab.css`)을 적용하여 구조 유지 및 스타일 분리
